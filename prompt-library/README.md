# Ý AI? – Prompt Library

Thư viện prompt thực hành cho workshop **“Ý AI? – Từ ý tưởng đến sản phẩm”** dành cho Đại sứ Văn hóa.

- Học cách viết prompt theo 5 thành phần: Vai trò, Bối cảnh, Nhiệm vụ, Định dạng, Ràng buộc.
- 25 prompt mẫu theo 5 nhóm: Nội dung và truyền thông, Thiết kế và sáng tạo, Sự kiện và văn hóa, Hiệu quả công việc, Nghiên cứu và ý tưởng.
- Prompt Builder, Phòng khám prompt và AI Checklist.

## Bổ sung prompt

Toàn bộ nội dung prompt nằm trong `prompts-data.js`. Chép một khối trong mảng `prompts`, đổi `id` (không trùng), chọn `group` và `purpose`, sửa nội dung rồi commit. Trang tự hiển thị prompt mới, không cần build lại.

Ví dụ trong thư viện mang tính minh họa. Luôn kiểm chứng kết quả AI trước khi sử dụng.
